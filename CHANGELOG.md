# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] — 2026-10-07

### Added
- `--help` now shows usage examples; new `-models` flag lists all
  available models with their population counts.
- **All 27 registered models now ship with data** (previously 5): the full
  Dodecad, Eurogenes, HarappaWorld, Tolan, MDLP K27, K47, E11, Michal K25,
  puntDNAL and regional calculator families — 27k–188k SNPs, up to 47
  populations each. Catalog with per-model sources in
  [docs/models.md](docs/models.md#model-catalog). Frequency matrices are
  embedded gzip-compressed (`<Model>.<N>.F.gz`), keeping binaries at
  ~205 MB (~190 MB compressed) instead of ~490 MB.
- **VCF and gVCF input support** (`-v vcf`/`-v gvcf`, or automatic content
  detection): matches model SNPs by rsID and, when no rsIDs are present, by
  chromosomal position on hg19 or hg38 (auto-detected from contig lengths,
  override with `-b`). gVCF reference blocks resolve homozygous-reference
  calls. Uses a coordinate index (`positions.tsv`, generated by
  `cmd/snpindex` from UCSC dbSNP b151 tables), embedded in the binary.
- SNP match statistics: every run now reports how many model SNPs were
  found in the input (`matched_snps` / `total_snps`), essential for judging
  the quality of VCF-based results.
- `-pretty` CLI flag: terminal bar-chart output instead of plain numbers
  (colors auto-disabled on non-TTY / `NO_COLOR`).
- LivingDNA vendor support (`-v livingdna`, same layout as 23andMe).
- HTTP API: `/health` endpoint, `build` form field, `-port`/`-addr` flags.
- CI: GitHub Actions workflow (build + race tests on Linux/Windows/macOS,
  gofmt, vet, golangci-lint) and Dependabot.
- Release automation via GoReleaser (`v*` tags produce draft releases with
  binaries for linux/windows/macos, amd64/arm64).
- Makefile, `cmd/snpindex` index generator, LICENSE (GPL-3.0), CHANGELOG.

### Changed
- **Default API server port is now 2364** (was 3162). Override with `-port`
  or the `PORT` environment variable.
- **JSON output is now an array** of result objects
  (`{"model", "proportions", "matched_snps", "total_snps"}`) instead of a
  bare `{model: {population: share}}` map — a breaking change for scripts.
- Go module path is now `github.com/emre-tarhan/admixture`.
- Documentation rewritten and expanded (`docs/architecture.md`,
  `docs/cli.md`, `docs/api.md`, `docs/models.md`).

### Fixed
- CI: golangci-lint pinned to v2 (v1 binaries refuse Go 1.25 modules);
  CLI test temp files are now closed so Windows cleanup does not fail.
- README claimed the server listens on port 8080.
- `build.sh` hardcoded `/usr/local/go/bin/go`.
- Documentation now clearly separates which models have embedded data
  (initially 5 of 27; all 27 as of this release) and credits the data
  sources.
